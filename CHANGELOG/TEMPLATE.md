# Changelog format

Each runtime surface has one append-only lane. Add the newest entry directly
below its header, use `YYYY-MM-DD`, explain the user-visible reason in one to
three sentences, cite the code commit, and cross-link other affected lanes.

```md
## YYYY-MM-DD — Imperative title
What changed and why. Note the user-visible effect.
**Commit**: `abc1234`. **Author**: Name.
**Touches**: `CHANGELOG/other/lane.md`
```
